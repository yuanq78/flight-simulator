# AeroSim X — 超写实飞行模拟器

基于 WebGL (Three.js) 的浏览器飞行模拟器，无需构建、无外部运行时依赖（Three.js 已本地化到 `libs/`）。

## 运行

需要通过 HTTP 服务访问（ES Modules 限制）：

```bash
./start.sh          # 或: python3 -m http.server 8000 / npx serve
```

然后打开 http://localhost:8000

## 特性

**飞行动力学（6-DOF）**
- ISA 标准大气模型（温度/气压/密度随高度变化，IAS/TAS/Mach 换算）
- 升力/阻力/诱导阻力、失速模型（失速迎角、翼尖下沉、抖振）
- 螺旋桨推力模型（转速响应、功率限制、高度衰减）
- 地面效应、机腹/硬着陆/地形撞击检测
- 起落架收放、襟翼两档、俯仰配平、刹车、前轮转弯
- 燃油消耗模型

**环境**
- 程序化地形（山脊噪声山脉、湖泊、森林、岩石、草地跑道）
- 大气散射天空、昼夜循环、星空、太阳/月光、闪电
- 四种天气：晴朗 / 少云 / 阴天 / 雷暴（风切变、降雨、颠簸）
- PBR 材质 + 环境反射 + ACES 色调映射 + 实时阴影

**座舱与仪表**
- 追尾 / 座舱 / 环绕三种视角（座舱视角带鼠标观察）
- 合成视效 HUD：姿态仪、空速/高度胶带、航向带、风向、警告
- 座舱面板仪表（动针：空速表、高度表、转速表、油量表）
- 小地图（地形、云、跑道、航向）

**音频**（WebAudio 合成）
- 引擎（转速随油门）、风噪、失速抖振、雨声、雷声

## 操作

| 按键 | 功能 |
|---|---|
| ← → ↑ ↓ | 横滚 / 俯仰 |
| A / D | 方向舵 |
| W / S | 油门 |
| F / G | 襟翼 / 起落架 |
| B / T | 刹车 / 配平（Shift 反向） |
| C / P / H / ` | 视角 / 暂停 / 帮助 / 遥测 |
| 1 / 2 / 3 | 时间流速 1× / 60× / 3600× |
| R | 重置飞行 |

支持游戏手柄（左摇杆驾驶，RT/LT 油门）。

## 起飞提示

油门加满滑跑，约 60 节后带杆离地；降落时襟翼 2 档、65 节进近，接地前拉平。
